# control-prestamos-biblioteca

sistema para controlar los prestamos y devoluciones de libros de la biblioteca



\## Objetivo

Desarrollar un sistema que permita administrar el registro de libros, estudiantes, préstamos y devoluciones de la biblioteca escolar, facilitando el control y la consulta de la información.



\## Integrantes del equipo

\- Eduardo: Integrante 1

\- Andrea: Integrante 2

\- Camila: Integrante 3



\## Funciones principales

\- Registrar libros.

\- Consultar libros disponibles.

\- Registrar préstamos y devoluciones.

\- Registrar fechas límite de devolución.

\- Identificar préstamos atrasados.

\- Registrar estudiantes.
